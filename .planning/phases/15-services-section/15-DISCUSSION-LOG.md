## Process / interaction format (meta, raised by user)

The discussion began in the UI question→response selector format. The user stopped it: "i feel trapped by selectors." Switched to plain-chat discussion. The user noted this format had skewed OFFER.md (Phase 14) toward a tidy ascending ladder because each forced single answer hid nuance.

**Outcome:** added an "Interaction format" rule to `CLAUDE.md` banning the selector format for this project (overrides GSD/impeccable/superpowers); pose options in chat, free-type responses. Also instructed: do not "lock" decisions hard — keep everything flexible to launch.

## Ladder vs tiers layout

| Option | Description | Selected |
|--------|-------------|----------|
| Sequence / progression | Numbered/connected journey 1→2→3 | partial |
| Different-by-design | Distinct blocks, own output/shape/copy | ✓ |
| Lead with entry, then options | Foreground one start, others as "next" | ✓ |
| Copy carries it | Clean 3-up + a framing line | ✓ (blend) |

**User's choice:** A blend of copy + design + lead-with-entry. Key reframe: the services are **not necessarily a sequence** — some may be, some not, and the set will grow. Closer to a product catalogue than a ladder. Each product shown as an easy-to-buy package; not e-commerce (CTA = book a call about that thing). Themed but distinct via colour + imagery + copy, like a product-selection grid.
**Notes:** This reframe ultimately reopened the whole offer (see Offer rebuild below).

## Offer rebuild (suite, strat-bombs, retainer, agency)

The reframe above led the user to conclude OFFER.md was built on a wrong premise and to rebuild it. Architecture agreed:

- **Strategy Suite** (connected): Diagnosis → Strategy → Embedding. Noun titles. Embedding **redefined** from a retainer to a bounded implementation project ("stays until the change is real, and measured"), priced per project.
- **Strat-bombs** (grid, 3 at launch): Market-fit Analysis £3,500 · ROAS booster £3,500 · CX alignment guide £7,000.
- **Retainer** (single offer, 3 levels as roles): Advisor £2k / Consultant £4k / Team member £6k per month. 3-month min, rolling after, discounts for longer. 6-month timeline visual. Distinct from Embedding (open-ended vs bounded).
- **For agencies** (price hidden): availability + pedigree (Havas Lynx, TBWA, MediaCom), references on request.

**Ownership:** Jamie decides/builds this pass; Kris does final voice/content tweaks. Copy/prices marked `[PROVISIONAL]` in OFFER.md.
