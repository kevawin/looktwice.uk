## Trust Boundaries

Static HTML/CSS/vanilla-JS site on Cloudflare Pages. No backend, no DB, no auth, no form, no user-supplied input. The only inputs to the new JS are: scroll position, viewport size, and the user's own click/keydown on the burger — all browser-native events on static elements. No data crosses a network trust boundary in this plan.

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-08-04 | Tampering | floating-bar JS DOM manipulation | mitigate | JS only toggles classes and aria attributes via classList/setAttribute on static elements. No innerHTML, no template strings into the DOM, no eval — no XSS sink introduced. There is no untrusted input to inject. |
| T-08-05 | Information Disclosure | mailto / #contact CTA target | mitigate | CTA pill links to `#contact` (in-page anchor), pills to `#approach`/`#work`. No external URL, no data exfil. Verify the CTA href resolves to the existing #contact section (covered by acceptance criteria). |
| T-08-06 | Denial of Service | scroll/resize listeners | accept | Listeners use `{ passive: true }` and toggle a class — O(1), no layout thrash beyond a class toggle. Native browser throttling applies. Negligible. |
| T-08-07 | Elevation of Privilege (a11y keyboard trap) | burger menu focus management | mitigate | Escape always closes and returns focus to the burger; opening moves focus to the first pill; closing on pill-click returns focus appropriately. Desktop pills stay reachable as plain anchors. No focus trap — verified by the Plan 03 Playwright focus-trap + return test. |
| T-08-SC | Tampering | npm/pip/cargo installs | accept | No package installs in this plan — vanilla JS/CSS only per CLAUDE.md (no frameworks, no npm). N/A. |

ASVS L1 note: no HIGH-severity threats on a static brochure site with no data collection. The only real correctness risk is keyboard accessibility (T-08-07), mitigated in code here and verified by automated tests in Plan 03.
