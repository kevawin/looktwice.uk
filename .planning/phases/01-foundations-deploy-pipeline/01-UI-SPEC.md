# Phase 1 — UI Design Contract

> Visual and interaction contract for Phase 1: Foundations & Deploy Pipeline.
> Generated by gsd-ui-researcher. Verified by gsd-ui-checker.
>
> Scope: page shell baseline, sticky top nav (transparent → Linen on scroll),
> mobile hamburger overlay, and minimal footer placeholder. All section bodies
> are empty in this phase — no hero, no situation, no services, no contact content.

---

| Property | Value |
|----------|-------|
| Tool | none — vanilla CSS, five-file split |

## Spacing Scale

All tokens defined in `css/tokens.css` as CSS custom properties. Executor references
`var(--token)` only — never hard-codes values.

| Token | Value | Phase 1 usage |
|-------|-------|---------------|
| `--space-xs` | 8px | Icon gaps, inline padding |
| `--space-sm` | 16px | Nav internal padding (vertical) |
| `--space-md` | 32px | Nav horizontal gap between links |
| `--space-lg` | 64px | Footer vertical padding |
| `--space-xl` | 96px | Not used in Phase 1 (reserved for mobile section padding in Phases 2–4) |
| `--space-section` | 120px | Not used in Phase 1 (empty section shells have no padding yet) |

Touch target minimum: hamburger button 44×44px (WCAG 2.5.5). This is the only
exception to the 8-point scale in Phase 1. Nav height on desktop: not constrained
by a fixed value — let content + padding define it.

Exceptions: 44px touch target for hamburger button only.

Source: DESIGN-TOKENS.md spacing block

## Typography

All tokens defined in `css/tokens.css`. Phase 1 uses Label and a wordmark-scale
only. Display, Headline, Title, and Body are declared in `tokens.css` but not
visually exercised until later phases populate the sections.

| Role | Token | Size | Weight | Line Height | Letter Spacing | Phase 1 element |
|------|-------|------|--------|-------------|----------------|-----------------|
| Display | `--text-display` | `clamp(3rem, 7vw, 5.5rem)` | 700 | 1 | -0.02em | Declared in tokens, not exercised |
| Headline | `--text-headline` | `clamp(1.75rem, 3.5vw, 2.75rem)` | 700 | 1.1 | -0.01em | Declared in tokens, not exercised |
| Title | `--text-title` | `clamp(1.25rem, 2vw, 1.5rem)` | 700 | 1.2 | — | Declared in tokens, not exercised |
| Body | `--text-body` | `clamp(1rem, 1.5vw, 1.1rem)` | 400 | 1.7 | — | Declared in tokens, footer placeholder if used |
| Label | `--text-label` | `0.8rem` | 400 | 1.4 | 0.1em (uppercase only) | Nav links, wordmark-adjacent, footer |
| Wordmark | (no token — inline) | `clamp(1.4rem, 2.5vw, 1.7rem)` | 700 | — | 0.04em | Nav wordmark "Look Twice" |

Rules:
- Weights are 700 or 400 only. Never 500. Never anything else.
- Label is uppercase when used as a nav link, chip, or footer element.
- Body is never uppercase.
- Line length cap: `--measure: 65ch` applied to `<p>` and body containers.

Source: DESIGN-TOKENS.md typography block, HOMEPAGE-SPEC §1 Navigation, DESIGN.md §3

## Color

All tokens defined in `css/tokens.css` as OKLCH values. The 60/30/10 split below
describes the page shell at Phase 1 completion — empty sections will be Linen by
default until later phases paint them.

| Role | Token | OKLCH value | Hex approx. | Usage in Phase 1 |
|------|-------|-------------|-------------|------------------|
| Dominant (60%) | `--color-linen` | `oklch(97% 0.01 80)` | #F9F6F1 | Page body background, nav scrolled state, empty section surfaces |
| Secondary (30%) | `--color-midnight` | `oklch(24% 0.04 275)` | #26263E | Nav wordmark text, nav links (scrolled state), mobile overlay surface, footer |
| Accent — Hot Pink (10%) | `--color-hot-pink` | `oklch(52% 0.28 0)` | #E0006E | Nav link hover underline (2px, offset 3px). No other use in Phase 1. |
| True White | `--color-true-white` | `oklch(100% 0 0)` | #FFFFFF | Nav wordmark + links (transparent/hero state), mobile overlay link text |
| Transparent nav state | — | transparent | — | Nav background before first scroll |

Additional tokens declared in `tokens.css` for use in later phases (not active
visual surfaces in Phase 1):
- `--color-signal-orange`, `--color-warm-amber`, `--color-deep-teal`,
  `--color-rich-purple`, `--color-cool-indigo`, `--color-link-sage`, `--color-link-pine`
- `--gradient-brand` (sticky tab only — Phase 4 exclusively)

Accent reserved for (Phase 1 only):
- Hot Pink underline on nav link hover and active state — nothing else.

The brand gradient (`--gradient-brand`) does NOT appear anywhere in Phase 1.
It is declared in `tokens.css` but its only permitted use is the sticky tab (Phase 4).

Banned: mid-tone grey backgrounds, glassmorphism, card shadows, gradient text.

Source: DESIGN-TOKENS.md colour block and "Colour Usage Rules", CONTEXT.md locked decisions

## Component Inventory

These are the only components built in Phase 1. All others (buttons, chips, cutout
mask, sticky tab, scroll reveal) are declared in `tokens.css` / `components.css`
as CSS specs but carry no visible UI until the phases that use them.

### 1. Sticky Top Nav (`.nav`)

**HTML structure:**
```html
<nav class="nav" aria-label="Primary navigation">
  <a class="nav-wordmark" href="/">Look Twice</a>
  <button class="nav-hamburger" aria-expanded="false" aria-controls="nav-overlay" aria-label="Open menu">
    <!-- hamburger icon: CSS lines or inline SVG -->
  </button>
  <div class="nav-links" role="list">
    <a class="nav-link" href="#work" role="listitem">WORK</a>
    <a class="nav-link" href="#approach" role="listitem">APPROACH</a>
    <a class="nav-link" href="#contact" role="listitem">CONTACT</a>
  </div>
</nav>
```

**States:**

| State | Background | Wordmark colour | Link colour |
|-------|------------|-----------------|-------------|
| Default (over hero, no scroll) | transparent | `--color-true-white` | `--color-true-white` |
| Scrolled (`.nav.scrolled`) | `--color-linen` | `--color-midnight` | `--color-midnight` |

**CSS spec:**
```css
.nav {
  position: sticky;
  top: 0;
  z-index: 100;
  background: transparent;
  transition: var(--transition-nav); /* 200ms ease-out */
  display: flex;
  align-items: center;
  justify-content: space-between;
  padding: var(--space-sm) calc(var(--space-lg) * 0.75); /* 16px 48px */
}

.nav.scrolled {
  background: var(--color-linen);
}

.nav-wordmark {
  font: 700 clamp(1.4rem, 2.5vw, 1.7rem) var(--font-primary);
  letter-spacing: 0.04em;
  text-decoration: none;
  color: inherit; /* inherits from nav state */
}

.nav-link {
  font: 400 var(--text-label) var(--font-primary);
  letter-spacing: var(--ls-label);
  text-transform: uppercase;
  text-decoration: none;
  color: inherit;
  position: relative;
}

.nav-link::after {
  content: '';
  position: absolute;
  bottom: -3px;
  left: 0;
  width: 0;
  height: 2px;
  background: var(--color-hot-pink);
  transition: width 180ms ease-out;
}

.nav-link:hover::after,
.nav-link.active::after {
  width: 100%;
}
```

**JS behaviour (NAV-01, NAV-02):**
```js
const nav = document.querySelector('.nav');
window.addEventListener('scroll', () => {
  nav.classList.toggle('scrolled', window.scrollY > 0);
}, { passive: true });
```

Nav colour (text) transition: When nav is over the hero (transparent state), wordmark
and links are White. After `.scrolled` is applied, they switch to Midnight. Handle this
with CSS `color` on `.nav` itself:

```css
.nav { color: var(--color-true-white); }
.nav.scrolled { color: var(--color-midnight); }
```

### 2. Mobile Hamburger Overlay (`#nav-overlay`)

**Trigger:** hamburger button tap/click  
**Breakpoint:** active at `max-width: 1024px` (hide desktop `.nav-links`, show hamburger)

**HTML structure:**
```html
<div id="nav-overlay" class="nav-overlay" aria-hidden="true">
  <button class="nav-overlay-close" aria-label="Close menu"><!-- × or SVG --></button>
  <nav aria-label="Mobile navigation">
    <a class="nav-overlay-link" href="#work">WORK</a>
    <a class="nav-overlay-link" href="#approach">APPROACH</a>
    <a class="nav-overlay-link" href="#contact">CONTACT</a>
  </nav>
</div>
```

**States:**

| State | Transform | aria-hidden on overlay | aria-expanded on button |
|-------|-----------|------------------------|-------------------------|
| Closed | `translateY(-100%)` | true | false |
| Open (`.nav-overlay.open`) | `translateY(0)` | false | true |

**CSS spec:**
```css
.nav-overlay {
  position: fixed;
  top: 0;
  left: 0;
  right: 0;
  z-index: 200;
  background: var(--color-midnight);
  transform: translateY(-100%);
  transition: transform 280ms cubic-bezier(0.16, 1, 0.3, 1); /* ease-out-quart */
  padding: var(--space-lg);
  display: flex;
  flex-direction: column;
  gap: var(--space-md);
}

.nav-overlay.open {
  transform: translateY(0);
}

.nav-overlay-link {
  font: 400 var(--text-label) var(--font-primary);
  letter-spacing: var(--ls-label);
  text-transform: uppercase;
  text-decoration: none;
  color: var(--color-linen);
}

.nav-overlay-close {
  align-self: flex-end;
  /* 44×44px minimum touch target */
  min-width: 44px;
  min-height: 44px;
  color: var(--color-linen);
  background: transparent;
  border: none;
  cursor: pointer;
}
```

**JS behaviour (NAV-04, NAV-05):**
```js
const hamburger = document.querySelector('.nav-hamburger');
const overlay = document.querySelector('.nav-overlay');
const close = document.querySelector('.nav-overlay-close');

hamburger.addEventListener('click', () => {
  const isOpen = overlay.classList.toggle('open');
  hamburger.setAttribute('aria-expanded', isOpen);
  overlay.setAttribute('aria-hidden', !isOpen);
});

close.addEventListener('click', () => {
  overlay.classList.remove('open');
  hamburger.setAttribute('aria-expanded', 'false');
  overlay.setAttribute('aria-hidden', 'true');
});

// Close overlay on link click
overlay.querySelectorAll('a').forEach(link => {
  link.addEventListener('click', () => {
    overlay.classList.remove('open');
    hamburger.setAttribute('aria-expanded', 'false');
    overlay.setAttribute('aria-hidden', 'true');
  });
});
```

No backdrop blur. No glassmorphism. Overlay is solid Midnight only.

## Interaction Contracts

### Nav scroll transition (NAV-01)

- Trigger: `window.scrollY > 0`
- What changes: nav background transparent → `var(--color-linen)`, text color White → Midnight
- Duration: `--transition-nav` = `background-color 200ms ease-out, color 200ms ease-out`
- Listener: `{ passive: true }`
- No shadow, no blur at any state

### Mobile overlay open/close (NAV-04, NAV-05)

- Trigger: hamburger button click
- What changes: overlay slides from `translateY(-100%)` to `translateY(0)`
- Duration: 280ms `cubic-bezier(0.16, 1, 0.3, 1)` (ease-out-quart)
- aria states toggle on both hamburger button and overlay element
- Close on: close button click, any overlay nav link click

### Nav link hover (NAV-03)

- What changes: Hot Pink underline grows from `width: 0` to `width: 100%`
- Duration: 180ms ease-out
- Underline spec: 2px solid `var(--color-hot-pink)`, offset -3px below baseline
- No background change on hover, no colour change on link text

### Smooth anchor scroll

- Method: `scroll-behavior: smooth` in CSS on `html` element
- Suppressed under `prefers-reduced-motion: reduce`:
  ```css
  @media (prefers-reduced-motion: reduce) {
    html { scroll-behavior: auto; }
  }
  ```

## Accessibility Contract

Minimum WCAG AA on all active Phase 1 surfaces.

| Surface | Text | Contrast obligation | Note |
|---------|------|---------------------|------|
| Linen nav (scrolled) | Midnight | AAA (passes by design) | Verify |
| Midnight overlay | Linen | AAA (passes by design) | Verify |
| Transparent nav over hero | White | Must pass AA on Hot Pink surface | Phase 2 concern — hero not present yet; Phase 1 transparent nav sits over Linen page body, which passes |
| Hot Pink underline | — | Decorative only, not text | No contrast requirement |

Keyboard and aria requirements for Phase 1:
- Hamburger button: `aria-expanded` toggles between `"true"` / `"false"` on open/close
- Hamburger button: `aria-controls="nav-overlay"`
- Overlay: `aria-hidden` toggles between `"true"` / `"false"`
- Nav landmark: `<nav aria-label="Primary navigation">`
- All nav links keyboard-reachable in visual order (tab order: wordmark → links → hamburger when mobile)
- Hamburger and close button: minimum 44×44px touch target
- Focus rings: visible on all interactive elements (links, buttons). Use:
  ```css
  :focus-visible {
    outline: 2px solid var(--color-hot-pink);
    outline-offset: 3px;
  }
  ```

`prefers-reduced-motion: reduce`:
- Nav transition: still transitions colour (opacity + bg-color only are safe), remove
  transform-based transitions. Nav has no transform anyway — colour transitions are fine.
- Overlay: remove the `transform` transition, show/hide via visibility or instant display
  toggle instead:
  ```css
  @media (prefers-reduced-motion: reduce) {
    .nav-overlay { transition: none; }
  }
  ```
- Smooth scroll: `scroll-behavior: auto` under reduced-motion (see above).
